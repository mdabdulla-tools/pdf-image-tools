Image Resizer — Resize by Pixels or Ratio

Resize any photo to an exact pixel size, or pick an aspect ratio — square 1:1 for profile pictures, 16:9 for YouTube, 9:16 for Reels and Shorts, or the original ratio. With the ratio lock on, typing a width sets the height automatically, so your photo never looks stretched.

The tool shows the original dimensions and file size as soon as you pick a photo, and the resized result can be downloaded as JPG or PNG.

How to use this Image Resizer tool

  1. Select a photo — its original size appears automatically.
  2. Type the width and height in pixels, or choose a ratio.
  3. Press “Resize & Download”.
