Image Compressor — Reduce Photo File Size

Shrink a photo’s file size for online forms, email and uploads without changing its dimensions. Move the quality slider down for a smaller file or keep it higher for better quality, then compare the size before and after.

This is the tool you need when a form says “photo must be under 100 KB” or an upload keeps failing. The compressed copy downloads as a JPG while your original photo stays untouched.

How to use this Image Compressor tool

  1. Select the photo you want to compress.
  2. Set the quality (70% is a good start).
  3. Press “Compress Image” and download the smaller JPG.

Private by design

Your file is processed entirely inside your browser, on your own phone or computer. It is never uploaded to a server, never stored, and never seen by anyone else — you can even use this tool offline after the page has loaded once.
